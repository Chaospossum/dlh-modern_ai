# Machine Learning Curriculum

Implementation of machine learning models for the Digital Learning Hub curriculum.

## Structure

- `machine_learning/` - Main directory for machine learning modules
  - `linear_models/` - Linear regression and related models
  - `tree_models/` - Decision trees, random forests, and boosting

## Requirements

- Python 3.11
- numpy 2.0.2
- scikit-learn 1.6.1
- shap 0.48.0
- pillow 11.3.0
